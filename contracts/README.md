# Smart Contracts

This directory is reserved for the Base L2 contract workspace. It will contain only contracts and tooling required for Gnosis CTF integration and KhmerFP settlement.

## Intended layout

- `src/` — minimal custom settlement or adapter contracts.
- `test/` — unit, fuzz, invariant, and fork tests.
- `script/` — reviewed deployment and administration scripts.
- `deployments/` — network-specific addresses and artifact metadata; never secrets.

No contract framework or dependency has been selected or installed yet.
