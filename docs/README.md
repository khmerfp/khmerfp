# KhmerFP Engineering Documentation

This directory holds reviewed architecture and operational documentation. It is separate from application code so decisions, security assumptions, and recovery procedures can be approved before implementation.

## Directories

- `adr/` — architecture decision records, including confirmed and pending decisions.
- `runbooks/` — operational procedures for incidents, reconciliation, deployments, and recovery.
- `threat-models/` — trust boundaries, assets, attack scenarios, and mitigations.

The current repository audit remains at the repository root in `KHMERFP_ARCHITECTURE_AUDIT.md`.
